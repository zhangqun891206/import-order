# 接口文档（V4 异步导入链路）

> Base URL：本地 `http://localhost:3000`，线上 `https://import-order-one.vercel.app`
> 统一响应包裹：`{ "ok": true|false, "data"?: ..., "error"?: string }`

## 1. 上传并创建任务
`POST /api/import-tasks`（multipart/form-data）

| 字段 | 类型 | 说明 |
|---|---|---|
| file | File | .xlsx/.xls/.docx/.pdf |
| ruleId | number | 解析规则 ID（见 /api/rules） |

响应（<1s 返回，不等待后台处理）：
```json
{ "ok": true, "data": { "task_id": "task_xxx", "trace_id": "trace_xxx", "status": "PENDING", "total_rows": 0, "total_batches": 0 } }
```
说明：单事务创建 import_tasks + 解析单元 + event_outbox；文件字节后台落库；后台 kick 推进队列。

## 2. 任务列表
`GET /api/import-tasks` → `data: [ { id, file_name, status, total_rows, processed_rows, success_rows, failed_rows, trace_id, degraded, created_at } ]`

## 3. 任务进度查询
`GET /api/import-tasks/:taskId`
```json
{ "ok": true, "data": {
  "task_id": "task_xxx", "file_name": "10000-orders.xlsx", "status": "PROCESSING",
  "total_rows": 10000, "processed_rows": 6000, "success_rows": 5988, "failed_rows": 12,
  "total_batches": 10, "completed_batches": 6, "trace_id": "trace_xxx",
  "degraded": false, "unverified_sku_rows": 0, "recent_errors": [ {"error_code":"E001","n":3} ]
} }
```
status 取值：PENDING/PROCESSING/COMPLETED/PARTIAL_SUCCESS/FAILED。轮询该接口会顺带推进队列（Serverless Consumer）。

## 4. 错误明细查询
`GET /api/import-tasks/:taskId/errors?batch=4&error_code=E001&page=1&page_size=50`
→ `data: { items: [ { id, batch_index, row_number, field_name, raw_value(脱敏), error_code, error_reason, suggestion, trace_id } ], total, page, page_size }`

错误码：E001 SKU不存在 / E002 必填缺失 / E003 电话格式 / E004 数量非正 / E005 外部编码重复 / E006 规则映射失败 / E007 写库失败 / E008 格式不支持。

## 5. 批次性能查询
`GET /api/import-tasks/:taskId/batches`
→ `data: { batches: [ {unit_id,batch_index,kind,status,rows_total,rows_ok,rows_err,retry_count} ], perf: [ {batch_index,parse_duration_ms,rule_duration_ms,validate_duration_ms,insert_duration_ms,total_duration_ms,status} ] }`

## 6. Trace 时间线
`GET /api/traces/:traceId` → `data: { trace_id, events: [ {event_name,event_status,message,unit_id,occurred_at} ] }`

## 7. Trace 搜索
`GET /api/traces?q=&error_code=&row=`（q 可为 task_id/trace_id/文件名）
→ `data: [ { task:{id,trace_id,file_name,status}, events:[...], errors:[...] } ]`

## 8. 监控聚合
`GET /api/import-monitor/summary`
→ `data: { throughput:[{m,rows}], backlog:{units,rows}, phase:{p_p50..r_p99}, error_distribution:[{error_code,n}], slow_batches:[...], task_status:[{status,n}] }`

## 9. 手动推进（Worker 入口）
`POST /api/internal/pump` body `{ "max_ms": 8000 }` → `data: { processed }`。供 scripts/worker.mjs / loadtest 常驻消费。
